# DHCP
* Dynamic Host Configuration Protocol
* IPアドレスを自動的に割り当てるプロトコル
* DHCPサーバ/DHCPクライアントからなる
  * DHCPサーバ: Windowsサーバ、Linuxサーバ、Ciscoルータ、家庭用ルータなど
  * DHCPクライアント: WindowsなどのPC、IP電話など
* DHCPパケット
  * UDP上で動作する
  * DHCPサーバ宛てパケットの宛先ポート番号は「67」（UDPヘッダにポート番号のフィールドがある）
  * DHCPクライアント宛てパケットの宛先ポート番号は「68」（同上）
  * DHCPメッセージ部分に、割り当てられるIPアドレス情報が書かれる
* DHCP通信の仕組み
  * DHCPクライアント → ブロードキャストアドレスにDHCP Discoverメッセージを送信（最初は自身のIPアドレス、DHCPサーバのIPアドレスいずれも知らないため）

# DNS(Domain Name System)
* 概要：https://www.infraexpert.com/study/tcpip15.html がわかりやすい
* リソースレコード
  * **A**
  * AAAA
  * **MX**
  * **CNAME**
  * **PTR**
  * **NS**
  * TXT
    * DKIM（DomainKeys Identified Mail）で公開鍵を定義する用途で使われることもある
  * SRV（Service）
    * そのドメインが提供するサービス名に対する、**サーバのホスト名とポート番号**を定義する
    * SRVレコードで定義するサーバ名には、仕様上、CNAME（つまりホストの別名）を指定することはできず、指定したホスト名に対応するA（AAAA）レコードでIPアドレスを指定する必要がある。つまり、クライアント側がSRVレコード要求→A（AAAA）レコード要求の順で名前解決できるようにする必要がある
