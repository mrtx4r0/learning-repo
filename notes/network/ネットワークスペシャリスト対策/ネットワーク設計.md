# 信頼性設計
## QoS(Quality of Service)
ネットワーク分野においては、通信品質を保証するための、ルータやレイヤ3スイッチに実装される制御・技術を指す<br>
* 以下の手法がある
  * 優先制御
  * アドミッション制御
  * ジェーピング(shaping)
  * ポリシング(policing)

# 負荷分散
* DNSラウンドロビン
* 負荷分散装置（Load Balancer）
  * ヘルスチェック（生存確認）
    * 障害が起こっているサーバにパケットを振り分けないようにするために行う
    * 負荷分散を行う主体は、Webサーバだけでなく、ファイアウォールやIDSなどのネットワーク機器もある
    * 具体的な方法としては、pingの定期的な送信、TCPセッションの確立、HTTPでのデータ送信など
* マルチホーミング
* **CDN**（Contents Delivery Network）
  * Webコンテンツを効率よく迅速にユーザに配信するための仕組み
  * 各地に配置された数多くのキャッシュサーバにWebコンテンツを一時的にキャッシュさせ、GSLB（Global Server Load Balancing）の機能によりリクエストしたユーザから近い場所にあるキャッシュサーバからコンテンツを配信する
  * 引用・参考：https://www.infraexpert.com/study/loadbalancer13.html
  * システム構成
    * オリジンサーバ
    * キャッシュサーバ
      * オリジンサーバから配信されるデータをキャッシュする
      * CDN事業者が提供する
      * 地理的に分散配置されたエッジサーバ
      * ユーザからのリクエストに代理応答する
    * GSLB
   * メリット
