# ポート番号
* well-known port：0～1023まで
* 主なポート番号とプロトコルの対応
  * TCP/20：FTP（データ）
  * TCP/21：FTP（制御）
  * TCP/22：SSH
  * TCP/25：SMTP
  * TCP/80：HTTP
  * TCP/110：POP3
  * TCP/143：IMAP
  * TCP/443：HTTPS
  * TCP/587：Submission（メール送信）
  * UDP/53：DNS
  * UDP/67：DHCP（サーバ）
  * UDP/68：DHCP（クライアント）
  * UDP/123：NTP
* ポートとプロトコルの対応表は以下にテキストファイルとして存在する
  * UNIX系・macOS：`/etc/services`
  * Windows NT系：`%SystemRoot%\System32\drivers\etc\services`
